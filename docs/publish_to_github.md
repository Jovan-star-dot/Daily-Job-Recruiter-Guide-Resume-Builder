# Publish and share the starter kit

Suggested repository name: `Daily-Job-Recruiter-Guide-Resume-Builder`.

## New repository through the GitHub website

1. Sign in to GitHub and open [Create a new repository](https://github.com/new).
2. Choose your account as owner and use the suggested repository name.
3. Use this description: `Step-by-step ChatGPT daily job search, candidate templates, truthful resume tailoring, and application QA.`
4. Choose Public if you want anyone to open the guide. Choose Private if you want to grant individual access. This repository should contain only the blank guide and templates.
5. Create the repository. You can leave initialization options empty because the starter kit includes a README.
6. On the repository page, choose the option to upload existing files. Open the unzipped starter-kit folder and upload its contents: README.md, START_HERE.md, prompts, templates, docs, and .gitignore. Preserve the folder structure. Upload the contents rather than the outer starter-kit folder so the README appears on the repository home page.
7. Commit with this message: `Add reusable Daily Recruiter Run guide and resume builder`.
8. Open README.md and follow START_HERE.md. Check that the relative file links open the correct files.
9. Share the repository URL. Each person downloads their own copy and supplies their own private profile and resume.

## Existing repository

Upload the whole `daily-job-recruiter-guide-resume-builder` folder into the chosen existing repository. It remains separate from other projects. Link directly to that folder's README. Do not replace an existing repository README or modify other projects as part of uploading this kit.

## What belongs in the shared repository

Upload the guide, prompts, blank templates, and .gitignore. Keep completed profiles, private source-file references, resumes, trackers with actual jobs, and generated application packages in your private workspace.

The repository shares instructions; it does not share your ChatGPT task, accounts, candidate documents, or connected-app permissions. Each person sets up their own run.
