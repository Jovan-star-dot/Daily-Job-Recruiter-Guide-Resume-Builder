# Build one resume

Upload your master resume and profile. Provide the full job description and its URL; a URL alone may be inaccessible. Copy this prompt below them.

```text
Build a tailored resume for the job description I supplied using only my master resume, Candidate_Profile.md, and confirmed Proof_Points.md.

Read the actual job requirements. If using a URL, open it; if inaccessible, use the full description I supplied and clearly state that live status is unverified. Confirm the company and role. Map key requirements and ATS terms to candidate evidence, separating direct evidence, transferable evidence, and missing qualifications. Ask about essential eligibility conflicts before presenting the role as a viable application.

Tailor the summary, skill order, and experience bullets around supported evidence. Never invent dates, experience, credentials, metrics, tools, or proficiency. Keep academic projects identified and contribution accurately scoped. Remove unsupported claims rather than including them with caveats.

Use my master resume as the content and layout reference. Preserve readable single-column formatting, standard headings, typography hierarchy, margins, and spacing. Follow my profile's chosen length and fill pages naturally when supported content permits, without filler or overflow. Keep the original master file unchanged.

Create an actual DOCX if document tools are available. Render and inspect all pages before delivery. If any step is unavailable, provide draft text and identify the missing document or layout checks. Never claim a file exists or was inspected when it was not.

Perform a fresh QA pass against the original sources and posting; revise up to 3 passes as needed. Deliver the resume, requirements/ATS evidence map, gaps, and QA verdict (APPROVED, NEEDS YOUR REVIEW, or REJECT JOB). APPROVED means internal checks passed; I still review before applying. Do not send or submit anything. Update my accessible tracker if provided, or give me a row to add; do not mark Applied.
```
