# Setup prompt

Upload your completed Candidate_Profile.md, master resume, and tracker. Copy the entire prompt below into your own recruiter chat.

```text
Help me set up my Daily Recruiter Run from the files I uploaded.

Read Candidate_Profile.md, Master_Resume_ATS.docx, and Job_Tracker.md. Read any optional resume PDF, cover-letter template, Job_Preferences.md, Career_Goals.md, and Proof_Points.md that I provided. Do not claim you read a file that you cannot access.

1. Confirm my target roles, level, geography, work arrangement, salary policy, eligibility, deal-breakers, career goals, minimum score, search breadth, package limit, resume format, daily time, and IANA timezone. Identify unfilled template fields and conflicting facts. Ask only for essential missing information. Never infer citizenship, sponsorship, availability, or completed degrees from unrelated facts.
2. Check whether web search, file reading, document creation, rendering/visual inspection, persistent tracker updates, and scheduling are available. Say which capabilities are untested until a test proves they work. If a capability is unavailable, give the relevant manual alternative without claiming full automation works.
3. Using only my supplied facts, produce completed Job_Preferences.md, Career_Goals.md, and Proof_Points.md. Preserve unknowns and attach each metric to the correct role/project. My master resume controls employment, education, and credentials; ask about conflicts instead of silently overwriting them.
4. Prepare a private source-file manifest of exact filenames and accessible persistent references where available. If files cannot be saved, give me their full text to save and reattach. Use the same tracker identity for future updates when supported.
5. Preserve the master resume as the content and layout reference. Do not overwrite it. Do not invent accomplishments to fill space. Follow my chosen length while keeping readable text and natural spacing.
6. Summarize the confirmed setup and remaining blockers. Do not schedule anything yet. Wait for me to paste the manual daily-run prompt and test it first.

My workflow is Search → Verify → Deduplicate → Hard Filter → Score → SWOT/ATS → Resume → QA → Final Package → My Review. Prepare application materials for my review. Do not submit applications, send emails, or contact employers or recruiters.
```
